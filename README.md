# codeofnature.github.io

Prosta strona główna / hub projektów dla GitHub Pages.

## Pliki
- `index.html` — cała zawartość strony
- `style.css` — wygląd i responsywność
- `assets/favicon.svg` — favicon

## Publikacja
1. Utwórz publiczne repozytorium `codeofnature.github.io`.
2. Wgraj zawartość tego katalogu do głównej gałęzi repo.
3. Wejdź w **Settings → Pages**.
4. W `Build and deployment` wybierz **Deploy from a branch**.
5. Wybierz `main` i `/ (root)`, a następnie **Save**.

Po publikacji strona powinna być dostępna pod:
`https://codeofnature.github.io/`
